My Local Oura Exporter is a local command-line application for downloading and exploring your own Oura data through the Oura API v2.

This website provides information about the application. It does not connect to your Oura account, accept tokens, or display health records.

What the application does

The application requests the personal datasets you authorize, such as sleep, activity, readiness, heart rate and workouts. It saves the returned records as JSON files on your computer. Optional CSV files and local summaries help you explore those records.

Data availability depends on your Oura account, granted permissions, membership, device and API support. The application remains subject to API compatibility verification; this page does not guarantee complete historical coverage.

How access works

Authorization takes place with Oura. The local application uses an OAuth access token that you provide in its local .env file. It sends authenticated requests directly to Oura's API and saves the results locally. This public website is not an OAuth callback or a token exchange service.

Where your data stays

The application has no hosted health-data service, analytics integration or advertising. It does not upload your exported records to this website or GitHub. You control your local files and any copies you choose to make.

Read the privacy notice for data handling and the terms of use for the application's intended purpose.

Contact

For questions about this personal application, use the contact email listed in its Oura application registration or consent details. Do not include an access token, authorization URL or health-data export in your message.

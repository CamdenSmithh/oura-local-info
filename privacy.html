Privacy notice

This notice describes My Local Oura Exporter, an independent application intended for its owner's personal use, and this informational website.

Oura data accessed by the local application

Depending on the permissions you grant and the datasets you select, the application may retrieve personal information and health-related records, including sleep, activity, readiness, heart rate, oxygen saturation, stress, heart health, workouts, sessions, tags, rest periods and ring information. Oura controls the available data and authorization process.

Purpose and storage

Records are retrieved to create a personal local archive and support local exploration. Raw records, derived CSV files and export manifests are stored in the application's data/ directory on the computer where you run it. The application does not provide a central server that stores or receives those records.

The access token is read from a local .env file or environment variable and sent to Oura in authenticated API requests. The application is designed to exclude the token from logs and exported artifacts. Keep your token private and protect your computer and backups.

Sharing and network requests

The application's health-data requests go directly to Oura's API. It does not send the downloaded records to this website, GitHub, advertisers or analytics providers. Public documentation verification accesses Oura's documentation. Installing development packages separately contacts the package registry.

If you independently copy, back up, synchronize or publish files, those actions may disclose data to the services you choose. Avoid uploading your .env file or data/ directory to a repository or website.

This website and its hosting

These pages contain no forms, account login, analytics scripts, advertising, third-party fonts or application cookies. They do not request access to your Oura account or receive your health records.

When hosted on GitHub Pages, GitHub provides the hosting infrastructure and may process information associated with website requests under the GitHub General Privacy Statement. External links take you to services with their own privacy practices.

Retention, deletion and revocation

Local exports remain until you delete them; repeated exports preserve previously downloaded history. Delete the local data/ directory and any other copies or backups to remove your exports. Delete the token from .env and any environment configuration to remove the local credential. Removing files does not revoke an Oura token.

You can revoke the application's authorization through Oura's account or connected-application controls. Revocation prevents future authorized access but does not remove files already exported. This application does not delete or modify records in your Oura account.

Contact and changes

Use the contact email associated with this application's Oura registration or consent details for privacy questions. Do not send credentials or full health-data exports. Updates to this notice will appear here with a revised date.
